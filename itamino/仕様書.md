# 痛みのカタチ 仕様書

最終更新：2026-10-22
対象ファイル：`index.html`（このフォルダ内。ビルド不要の単一ファイル）

---

## 1. 目的

患者が自分の痛みを**オノマトペ（擬態語）から選んで重ね合わせ**、その強さ・リズム・場所を指で整えることで、言葉だけでは伝えにくい痛みの「カタチ」を動く図として表せるようにする。最後に、本人が自分で名前をつけて10秒の動画として保存する。

想定端末は iPad の Safari（横向き・縦向きの両方に対応）。

---

## 2. ファイル構成と動作環境

| 項目 | 内容 |
|---|---|
| 本体 | `index.html` 1ファイル（HTML・CSS・JavaScript をすべて含む） |
| 外部読み込み | フォント：Google Fonts「Zen Maru Gothic」／3D描画：three.js r128（cdnjs） |
| データ保存 | なし（サーバーにも端末にも記録を残さない）。成果物は動画ファイルのみ |
| 3Dが使えない場合 | WebGL や three.js が読めないときは、2Dで描いた玉に自動で切り替わる |
| 動画保存 | `MediaRecorder` と `canvas.captureStream` を使用。iPadOS 14.5 以降の Safari が必要 |

`index.html` の中身は、次の順に並んでいる。

1. `<style>`：見た目（紙の色・クレヨン調・パネル配置・縦向き用レイアウト）
2. `<body>`：画面の骨組み（ヘッダー、ことば一覧、ステージ、リズム、調整ドロワー、名前シート、結果シート）
3. `<script>`：次の各部
   - ことばデータ：`CLUSTERS`（グループ）、`WORDS`（ことば）、`SCORES`（論文の得点）、`TYPES`（初期値をまとめたもの）
   - 調整バーの定義：`BARS`
   - 波の計算：`envelope`（時間の波）、`layerEnv`（途切れ方）、`spatial`（玉のまわりの形）
   - 画面部品の描画：ことば一覧、リズムレーン、調整バー
   - 3Dの玉（three.js）と、その回転
   - 指の操作（玉を回す／痛む場所を動かす）
   - 毎フレームの描画ループ
   - 名前入力と10秒録画、保存・共有

## 4. 操作の流れ

1. **ことばを選ぶ**：一覧のことばを押すと「層」が1つ増え、玉と輪が動き出す。同じことばを何度でも選べる。重ねられるのは最大6つまで。
2. **強さとリズムを整える**
   - リズムレーンを左右にドラッグ：その層のタイミング（ずれ）を変える
   - 「調整」→バーを上下：強さ・間隔・細かさ・鋭さ・広がりを変える
   - 玉そのものをなぞる：玉を回す（慣性あり。「正面に戻す」で元に戻る）
   - 玉のまわりをなぞる：選んでいる層の「痛む場所」を動かす。場所は玉の表面に固定されるので、玉を回すと一緒に回る
   - バーや玉のまわりを触っている間は、選んでいる層の輪だけを表示する。指を離して0.6秒後に、全体の表示に戻る
3. **名前をつけて保存**：本人が名前を入力すると10秒間録画する。名前は動画の中に描き込まれ、ファイル名は「名前_日付」になる。名前やオノマトペをアプリが自動で作ることはしない（本人のことばを優先する方針）。

## 5. 表現（ことば）の選定

### 5.1 出典

- **楠見 孝・中本 敬子・子安 増生（2010）「痛みの比喩表現の身体感覚と認知の構造」『心理学研究』80(6), 467–475**
  - 先行研究・擬態語辞典・Web上の用例から集めた痛みの表現98個（比喩58、擬態語40）を、大学生436名が評定した研究
  - 評定項目：痛む部位（16部位）、身体感覚の特徴7項目（持続時間・時間間隔・場所の変化・深さ・面積・体積・強さ）、イメージ7項目（鋭い–鈍い、熱い–冷たい など）、経験頻度
  - 評定結果を主成分分析し、その得点からクラスタ分析で11のグループ（A〜K）に分けている
- **付表1**（著者ページで公開。Web Archive から取得）：98表現それぞれの主成分得点
- **土斐崎ら（2014）**：「がーん」と、「ちくっ」の補足に使用

### 5.2 なぜこの41語なのか

- 論文の98表現のうち、**擬態語40語をすべて**採用した。比喩表現（「刃物で刺されたような」など58個）は採用していない。
  - アプリの目的が、オノマトペで痛みのカタチを表すことだから。
  - 論文によると、擬態語で表される痛みの経験頻度（平均2.23）は、比喩で表される痛み（平均2.05）より有意に高い。患者にとって身近なことばと言える。
- 擬態語40語は、論文の図1のグループ分けのとおりに C〜K の見出しの下に並べている。
  - **A（破壊）と B（突き刺す）は比喩表現だけのグループ**なので、一覧には出てこない。強い痛みのグループで擬態語を含むのは C だけ。
- 論文の一覧にない「**がーん**」を、土斐崎ら（2014）から1語追加した。「そのほか」として別枠で表示している。
- 一覧の大分けは、論文の記述どおり「強い痛み（C）」と「比較的弱い痛み（D〜K）」の2つ。

## 6. 波の作り方

### 6.1 考え方

ことばの性質のうち、研究で数値が出ているものは**ことばごとの得点**から初期値を決める。研究で決まっていないもの（波の形・細かさ・間隔）は、**グループの特徴から作った出発点**とする。どの値も、患者が自分の感覚に合わせて変えられる。この考え方は画面の出典欄にも書いている。

### 6.2 ことばごとの得点から決める値（付表1）

使う得点は5つ（図3・図4と同じ向きにそろえている）。

| 得点 | 意味 | 論文での解釈 |
|---|---|---|
| s0 | 身体感覚 第1主成分 | 全般的な強さ（体積・面積・持続・深さ・強さ） |
| s1 | 身体感覚 第2主成分 | ＋広い皮膚表面／−狭く深い |
| s2 | 身体感覚 第3主成分 | ＋持続的／−断続的（時間間隔の項目だけで高い負荷） |
| s3 | 認知的評価 第1主成分 | 圧迫痛（強さのイメージ）。現在は表示用のみで、波には使っていない |
| s4 | 認知的評価 第2主成分 | ＋鋭く堅い／−鈍く熱い |

> 注意：付表1では、図3の第1・第2主成分の列が、図とは符号が逆に載っている（例：「がんがん」は表ではマイナス、図では「強い」側）。アプリでは図の向きにそろえるため、この2列の符号を反転して使っている。

得点から初期値への変換（コード中の `scoreWave`）：

| バー | 計算式 | 範囲 |
|---|---|---|
| 強さ `amp` | 0.55 + 0.15 × s0 | 0.2〜0.95 |
| 広がり `spread` | 0.5 + 0.2 × s1 | 0.12〜1（1＝全体） |
| 鋭さ `sharp` | 0.5 + 0.2 × s4 | 0.05〜0.95 |
| 途切れ方 `depth`（バーなし） | 0.65 − 0.25 × s2 | 0.2〜1 |

「途切れ方」は、波の谷でどこまで痛みが下がるかを表す。1なら谷でゼロまで下がり（断続的）、小さいほど谷でも痛みが残る（持続的）。
例：「がんがん」「ちくちく」は 1.0（はっきり途切れる）、「ずーん」は 0.2（ほぼ途切れない）。

説明欄の一行（`scoreText`）は、得点が ±0.5 以上の項目だけを、強い／弱い、広い範囲／狭く深い、続く／途切れる、鋭い／鈍い・熱い、のことばに置き換えて表示する。

**例外**：「ちくっとする」の広がりは、土斐崎ら（2014）の「狭く短い」という結果に合わせて 0.2 に上書きしている。

## 7. 見た目の方針

- 白い紙の背景に、クーピー（色鉛筆・クレヨン）のような色と粒子感。以前の暗いネオン調はやめ、やわらかい見た目にした。
- 痛み全体＝灰色のガラス調の3Dの玉（不透明度は約70%）。縁が濃くなり、へこみやふくらみに沿った等高線と、うっすらとした緯線が入る。黒い繊維や白い毛糸の質感も試したが、見にくかったため採用しなかった。
- ことばごとの波＝玉のまわりを回るクレヨン調の輪。
- 鋭く外にとがった部分からは、色の粒が飛び散る。
- 指で触れた場所には、波紋が広がる。

## 8. 未確認の点・今後の課題

- **F01の表記**：論文の図1の文字は「きゅーんとする」、付表1は「ぎゅーんとする」で食い違っている。本文の考察でも、F群の例として「ぎゅーとする」が挙がっている。アプリは現在「きゅーん」のまま。紙面で確認が必要。
- **iPad実機での確認がまだ**（動作確認はパソコンのChromeのみ）。
- 波の形・細かさ・間隔は研究の裏付けがない出発点。患者の調整結果を集めれば、見直しの材料になる。
- 論文の参加者は大学生のみで、論文自身も、重い痛みの表現の評定には限界があると述べている。臨床の患者で同じ傾向になるかは確かめられていない。
- 付表4（グループごとの部位の選択率）は取得済みだが、まだアプリには使っていない。
